# cli-video — 영상을 AI 에게 읽히기

Gemini 는 **동영상 파일 자체를 읽는다.** 프레임을 뽑아 이미지로 넣을 필요가 없다.
`agy` CLI 를 통해 로컬 mp4 를 그대로 넘기고 분석 결과를 받아온다.

## 쓰는 법

```bash
python scripts/cli_video.py --video ad.mp4 --task "샷 단위로 나눠서 무엇이 보이는지 정리해줘"
python scripts/cli_video.py --video demo.mp4 --task "이 영상을 3문장으로 요약해줘" --model gemini-3.7-flash-medium
python scripts/cli_video.py --video ad.mp4 --task-file my_prompt.txt --out report.md
```

| 옵션 | 뜻 |
|---|---|
| `--video` | 분석할 영상 파일 (필수) |
| `--task` | 무엇을 알고 싶은지 (필수, `--task-file` 로 대체 가능) |
| `--task-file` | 긴 지시문을 파일로 넘길 때 |
| `--model` | 기본 `gemini-3.1-pro-high`. 가볍게 볼 땐 `gemini-3.7-flash-medium` |
| `--out` | 결과를 파일로 저장 (생략하면 화면 출력) |
| `--timeout` | 초 단위, 기본 600. 긴 영상은 늘려야 한다 |

## 잘 물어보는 법

그냥 "분석해줘"보다 **무엇을 원하는지 축을 정해서** 물으면 결과가 훨씬 쓸모 있다.

- "샷이 몇 개인지, 각 샷의 카메라 앵글과 길이를 표로 정리해줘"
- "등장인물의 옷과 소품이 영상 내내 일관되는지, 바뀌는 지점이 있으면 시각과 함께 알려줘"
- "이 광고가 시청자의 감정을 어떤 순서로 끌고 가는지 구간별로 설명해줘"
- "화면에 보이는 글자를 전부 시각과 함께 옮겨 적어줘"

## Claude 에게 이렇게 시키면 된다

- "이 mp4 를 agy 한테 읽혀서 샷 구성을 표로 정리하게 해줘."
- "이 영상에서 사람이 몇 명 나오고 언제 등장하는지 확인해줘."
- "레퍼런스 영상 분석해서 우리 영상 프롬프트로 옮겨 쓸 만한 요소를 뽑아줘."

## 알아둘 것

- 분석은 **길이에 비례해 오래 걸린다.** 1~2분 영상이 보통 1~3분, 긴 영상은 더 걸린다.
  기본 10분 대기이며 `--timeout` 으로 늘린다.
- 🔴 권한 플래그가 없으면 agy 는 **아무 답 없이 조용히 끝난다.** 스크립트가 항상 붙여준다.
- 파일 경로는 스크립트가 절대경로로 바꿔서 넘긴다 — 상대경로면 CLI 가 못 찾는 경우가 있다.
- 결과가 길면 `--out` 으로 파일에 받는 편이 낫다.
