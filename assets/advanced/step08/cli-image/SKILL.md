# cli-image — CLI 로 이미지 만들기

`codex` 와 `agy` 는 둘 다 이미지 생성 도구를 갖고 있다. 이 스킬은 **프롬프트를 보내고,
CLI 가 자기 폴더에 만들어 둔 파일을 찾아 내가 지정한 곳으로 가져온다.**

## 쓰는 법

```bash
python scripts/cli_image.py --tool agy --prompt "새벽 강가를 달리는 러너, 시네마틱" --out run.png
python scripts/cli_image.py --tool agy --prompt "제품 컷" --aspect 16:9 --out hero.png
python scripts/cli_image.py --tool codex --prompt "이 인물로 다른 포즈" --ref face.png --out pose.png
```

| 옵션 | 뜻 |
|---|---|
| `--tool` | `codex` 또는 `agy` (필수) |
| `--prompt` | 무엇을 그릴지 (필수) |
| `--out` | 저장할 경로 (필수). 확장자는 실제 형식에 맞게 자동 보정된다 |
| `--ref` | 참조 이미지. 여러 번 쓸 수 있다 |
| `--aspect` | **agy 전용** 화면비: `1:1 2:3 3:2 3:4 4:3 9:16 16:9` |
| `--timeout` | 초 단위, 기본 300 |

## 두 CLI 의 차이 (실측)

| | codex | agy |
|---|---|---|
| 화면비 지정 | 안 됨 (프롬프트로 부탁만 가능) | 됨 (`--aspect`) |
| 모델 선택 | 안 됨 | 안 됨 |
| 산출 형식 | PNG | JPG |
| 실측 해상도 | 1448x1086 급 | 1376x768 급 |
| 참조 이미지 | 됨 | 됨 |

**인물 일관성은 둘 다 유지된다.** 실측에서는 codex 쪽이 미세한 표식(점, 홍채색)까지 더 잘 잡았고,
화면비를 정확히 맞춰야 할 때는 agy 가 편하다.

## 알아둘 것

- 🔴 **CLI 는 자기 폴더에 파일을 만든다.** 그 위치를 스크립트가 찾아 `--out` 으로 복사해 온다
  (codex `~/.codex/generated_images/`, agy `~/.gemini/antigravity-cli/brain/`).
- 🔴 **agy 는 요청한 확장자와 다르게 저장한다** — png 로 부탁해도 실제로는 jpg 로 나온다.
  스크립트가 실제 형식에 맞춰 `--out` 확장자를 고쳐준다.
- 참조 이미지는 **작업 폴더 안에 두는 편이 안전하다.** 윈도우에서 codex 가 폴더 밖 절대경로의
  참조를 못 읽고 죽는 조합이 있다.
- 화면비는 근사치다. agy 의 `16:9` 는 실측 1.79 로 정확히 1.778 이 아니다.
