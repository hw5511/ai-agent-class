## 사전 확인
파이프라인 시작 전 반드시 확인:
1. 회의 메모 Google Docs URL 또는 파일 경로가 있는지 확인
   - 없으면: "회의 메모 Docs URL을 알려주세요" 요청
2. 임원 보고 수신 이메일 주소 확인
   - 없으면: "보고 이메일 수신자를 알려주세요" 요청

## 파이프라인 (5단계 순차 실행)

### STEP 1: 회의 메모 읽기
gws_skill.md의 Google Docs 읽기 기능으로 회의 메모를 읽는다.

파악할 것:
- 회의 일시 / 참석자
- 논의된 안건 목록
- 결정사항 및 담당자별 액션아이템
- 핵심 키워드 (시장조사에 활용)

### STEP 2: 회의록 정리 (work-docs 스킬)
work-docs 스킬을 실행한다.

시트 구성:
- 시트명: `[날짜] 회의록`
- 컬럼: 안건 / 결정사항 / 담당자 / 마감일 / 비고

### STEP 3: 업무 분장 Notion 등록 (work-meeting 스킬)
work-meeting 스킬을 실행한다.

등록 내용:
- STEP 1에서 파악한 액션아이템을 담당자별로 Notion Work DB에 등록
- 마감일 = 회의에서 언급된 날짜. 언급 없으면 1주일 후
- 유형 = "미팅"

### STEP 4: 시장 조사 (work-research 스킬)
work-research 스킬을 실행한다.

조사 내용:
- STEP 1에서 파악한 핵심 키워드로 네이버 데이터랩 검색량 조사
- 조사 결과를 STEP 2에서 만든 시트의 새 탭에 추가 저장

### STEP 5: 임원 보고 이메일 (work-email 스킬)
work-email 스킬을 실행한다.

이메일 내용:
- 제목: `[보고] [회의명] 결과 요약`
- 본문: 회의 요약 + 결정사항 + 조사 결과 요약 + 시트 링크
- 수신: 사전 확인에서 입력받은 임원 이메일

---

## 실행 규칙
- 각 단계 완료 후 자동으로 다음 단계 진행
- 에러 발생 시 해당 단계에서 멈추고 사유 보고, 이후 단계는 계속 진행
- 각 단계 완료마다 진행 상황 출력: `[STEP N/5 완료] 내용`
- 전체 완료 후 처리 결과 5단계 요약 보고

## 완료 보고 형식
```
[기획회의 자동화 완료]
- STEP 1: 회의 메모 읽기 완료 (안건 N개, 액션아이템 N개 파악)
- STEP 2: 회의록 시트 생성 완료 (링크: ...)
- STEP 3: Notion 업무 등록 완료 (N개 등록)
- STEP 4: 시장 조사 완료 (키워드 N개 조사)
- STEP 5: 임원 보고 이메일 발송 완료
```
