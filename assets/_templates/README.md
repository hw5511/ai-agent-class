# 슬라이드 템플릿

새 슬라이드를 만들 때 **처음부터 그리지 말고**, 아래에서 비슷한 형태를 찾아
복제한 뒤 파일명을 바꾸고 내용만 고친다.

```bash
cp assets/_templates/B_명령과_출력.svg assets/basic/step01/새_슬라이드.svg
```

각 템플릿에는 `[바꾸기]` 주석이 달려 있다. 그 자리만 고치고 **좌표는 건드리지 않는다.**

## 어떤 걸 복제할까

| 만들려는 것 | 복제할 파일 |
|---|---|
| 개념·원리를 카드 셋으로 설명 | `A_개념_카드3장.svg` |
| 명령어 하나 치고 결과 보여주기 | `B_명령과_출력.svg` |
| 같은 작업을 Windows / macOS 로 나눠서 | `C_윈도우_맥_2열.svg` |
| 여러 항목의 성공·실패를 한눈에 | `D_결과_체크리스트.svg` |
| VS Code 화면 전체(탐색기에 파일이 생기는 걸 보여줄 때) | 기존 `assets/basic/step01/agy_최종_폴더_구조.svg` 복제 |
| 실제 캡처를 창 프레임에 끼워 넣기 | 기존 `assets/basic/step01/agy_설치.svg` 복제 |

마지막 두 형태는 아직 템플릿으로 못 뽑았다. 당분간은 위에 적힌 실제 슬라이드를
복제해서 쓴다.

## 공통 규격 (1280 × 720)

| 요소 | 위치 |
|---|---|
| 과정 배지 | `x=60 y=44 w=78 h=24` · 글자 11px/600 |
| 단계 칩 | `x=150 y=44 w=66 h=24` |
| 제목 | `x=60 y=100` · 26px / 800 |
| 부제 | `x=60 y=140` · 15px · `#6b7280` |
| 본문 영역 | `y=168` 부터 `y≈636` 까지 |
| 각주 | `x=640 y=672` 가운데 정렬 · 13px · `#9ca3af` |

색: 파랑 `#2563eb` / 성공 `#4ade80` `#15803d` / 경고 `#fbbf24` `#92400e` /
실패 `#f87171` / 어두운 패널 `#1f2937` / 코드 글씨 `#a5f3fc`

## 만든 뒤 확인

1. XML 이 깨지지 않았는지
   `python3 -c "import xml.dom.minidom;xml.dom.minidom.parse('경로.svg')"`
2. `<` `>` `&` 가 글자로 들어갈 땐 `&lt;` `&gt;` `&amp;` 로 escape 했는지
3. 브라우저로 열어 **글자가 패널 밖으로 삐져나오지 않는지** 눈으로 확인
